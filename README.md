# Слово старца

Android-приложение: каждый день — короткое высказывание православных старцев и святых отцов.

## Что умеет

- **Слово дня.** Каждый день новая цитата. Порядок перемешан, но постоянен:
  повторов нет, пока не будут показаны все. Стрелками или свайпом можно
  листать вчера/завтра, кнопка «Ещё слово» — случайная цитата.
- **Напоминание.** Уведомление с сегодняшней цитатой в выбранное время
  (Настройки → «Присылать слово дня»). Работает и после перезагрузки телефона.
- **Поделиться и скопировать** любую цитату; **избранное** (сердечко).
- **Поиск** по тексту и автору.
- **Источники.** Каждый источник можно выключить (тогда его цитаты не
  попадают в слово дня), открыть ссылку, добавить в него цитату вручную или
  **списком** — вставить текст из книги или сайта:

  ```
  Смиряйся, и все дела твои пойдут.
  — Прп. Амвросий Оптинский

  Кто уступает, тот больше приобретает. || Прп. Амвросий Оптинский
  ```

  Кнопка «Источник» на вкладке «Источники» добавляет свой источник (книга, сайт, подборка).
- **Радио ВЕРА** — кнопка прямого эфира внизу экрана. Играет в фоне,
  останавливается из уведомления. Долгое нажатие открывает radiovera.ru.
  Адрес потока можно поменять в настройках.
- Светлая (пергамент) и тёмная тема, размер текста.

## Сборка APK

Как у «Клубка»: GitHub Actions собирает APK при каждом пуше в `main`.

1. Создать на GitHub пустой репозиторий и залить туда содержимое этой папки.
2. Через несколько минут APK появится в Actions (артефакт) и по постоянной ссылке
   `https://github.com/<владелец>/<репозиторий>/releases/latest/download/slovo-startsa.apk`.

В репозитории только свои файлы; остальную обвязку Android добавляет
`flutter create` во время сборки. APK подписывается постоянным ключом
`ci/debug.keystore`, поэтому обновления ставятся поверх старой версии без потери избранного.

Напоминания, «Поделиться», ссылки и радио сделаны на родном Android-коде
(`android/app/src/main/kotlin/…`) без сторонних плагинов — сборка зависит
только от `sqflite`.

Приложение — для личного пользования. Часть текстов (переводы Паисия
Святогорца, составительские сборники) защищена авторским правом; для
публикации в Google Play нужно согласовать их использование с издателями.

Шрифты: Old Standard TT и PT Serif (SIL Open Font License, см. `assets/fonts`).
